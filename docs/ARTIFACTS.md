# Review artifact access

This anonymous release includes the method, reproduction configurations,
CPU tests, evaluation data and recorded research media.

The training and evaluation entry points accept local checkpoint and motion
reference paths. See [Reproduction](REPRODUCIBILITY.md) and
[Quickstart](QUICKSTART.md) for the required files and checksums.

Checkpoint weights are not bundled in this code repository. Public model-hosting
accounts are not linked in this review release. Use the supplementary artifacts
made available through the submission system where applicable.
